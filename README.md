# book-sys.github.io
## English

Адреса: https://book-sys.github.io/english/

- `index.html` — увесь застосунок (Сьогодні, Трекер, Pimsleur, Домашка, Слова, Біркенбіль).
- `data.json` — домашка (`homework`) і текст тижня (`week_text`); його оновлюємо після кожного заняття.
- Позначки й прогрес зберігаються в пам'яті телефона (`localStorage`), як у спорт-календарі.
- Копія прогресу йде в Google-таблицю «English — прогрес» (Диск book@, папка «Особисте»): аркуші Дні, Pimsleur, Домашка, Стан. Пише туди Apps Script (`@OnlyCurrentDoc`, веб-застосунок «для всіх», лише приймає дані); його адреса — `SHEET_URL` в `english/index.html`. Надсилається не частіше ніж раз на 30 с і при закритті застосунку.
- Вкладка «Біркенбіль»: Розбір (пословний переклад `lines[].pairs` + переклад `uk`), Слухання (озвучка з підсвіткою слів, швидкість, «по колу», запис для фонового слухання), Вголос. Прогрес тижня — в аркуші «Біркенбіль».

### Аудіо тексту тижня (щотижня)

`english/tools/make_week_audio.py` бере `week_text` з `data.json`, озвучує кожне речення через edge-tts (`en-US-JennyNeural`, −15 %) і робить `english/audio/week-NN-sII.mp3` (по реченню, для «Слухання» з підсвіткою), `week-NN.json` (час кожного слова) і `week-NN.mp3` (увесь текст з паузами ~1,2 с, для фонового слухання), а в `week_text` дописує `"audio"` і `"timing"`.

```
pip install edge-tts        # один раз; ще потрібен ffmpeg
python english/tools/make_week_audio.py           # лише якщо текст змінився
python english/tools/make_week_audio.py --force   # перезробити
```

Помічник автовикладки на комп'ютері Марини запускає його сам, коли змінюється `data.json`, і викладає mp3 разом із ним.
