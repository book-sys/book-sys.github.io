# Спортивный календарь (личное)

Календарь, где отмечаю спортивные активности за месяц. Цель по умолчанию: 21 активность.
Открывается на айфоне иконкой с главного экрана.

- Ссылка: https://book-sys.github.io/sport/
- Файлы: `sport/index.html` (вся страница) и `sport/apple-touch-icon.png` (иконка 180×180)
- Сайт публикует GitHub Pages: всё, что лежит в репозитории `book-sys/book-sys.github.io`, появляется на `book-sys.github.io` примерно через минуту.

## Как устроено

- Одна HTML-страница, без сервера и без базы.
- Отметки хранятся в памяти телефона (localStorage), у каждой свои. Никуда не отправляются.
- На айфоне: Safari → «Поширити» → «Додати на початковий екран». Дальше открывать только через иконку: у иконки своё хранилище, отдельное от Safari.
- Если удалить иконку, отметки пропадут вместе с ней.
- Айфон запоминает иконку и название в момент добавления. Чтобы увидеть новую иконку, старую нужно удалить и добавить заново (отметки при этом пропадут).

## Что учитывается как активность

Включено по умолчанию:

- тренировка на тело, от 20 мин;
- бег, от 25 мин;
- велотренировка, от 30 мин;
- поход в зал;
- ходьба / прогулка, 10 000 шагов;
- йога, от 25 мин;
- растяжка / пилатес, от 25 мин;
- теннис, волейбол, командные игры, от 30 мин;
- скакалка, HIIT, кардио, от 15 мин.

Выключено, можно включить в ⚙: поход / хайкинг от 60 мин; ролики, коньки, самокат от 30 мин.
Убрали насовсем: плавание и танцы.

В ⚙ также меняется цель на месяц и режим подсчёта: «дни с активностью» (по умолчанию: две тренировки в один день дают один зачёт) или «каждую тренировку».

## Как сделать следующий месяц

В `sport/index.html` поменять:

1. `Y=2026, M=9`: год и номер месяца, считая с нуля (январь = 0, октябрь = 9, ноябрь = 10).
2. `KEY='sport-oct-2026'`: новое имя, например `sport-nov-2026`. Иначе новый месяц подтянет отметки старого.
3. Функция `key(d)`: там зашито `'-10-'`, поставить номер нового месяца (`'-11-'`).
4. Число дней: в коде `31` встречается несколько раз (циклы по дням и `daysLeft`). Для месяца в 30 дней заменить на 30.
5. Тексты: «октября» в карточке дня и подписи дня, `Октябрь 2026` под заголовком, `<title>` и `<h1>` (`Sport October`), название иконки `apple-mobile-web-app-title` (`Sport Oct`).
6. Иконка: перерисовать `apple-touch-icon.png`, если на ней стоит месяц (сейчас «21 / OCT»).

Проще всего попросить Claude: «сделай календарь на ноябрь по README в моём GitHub». Его можно положить рядом, в `sport-nov/`, чтобы октябрь остался как архив. Тогда ссылка будет `book-sys.github.io/sport-nov/`, и иконку нужно поставить заново.

## Как это публиковалось

- Репозиторий создан через сайт GitHub (у подключения Claude к GitHub нет прав на этот репозиторий, API отвечает 403).
- Файлы заливаются обычным `git clone` → правка → `git commit` → `git push` с компьютера Марины. Вход в GitHub уже сохранён на компьютере.
- Через 1–2 минуты после push страница обновляется на `book-sys.github.io/sport/`.
